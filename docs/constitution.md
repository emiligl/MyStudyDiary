# Constitución del Diario de Estudio

1. **Stack simple:** solo HTML, CSS y JavaScript nativos; sin dependencias ni build.
2. **Spec y código alineados:** ninguna funcionalidad se implementa fuera de una spec aprobada.
3. **Lógica separada de interfaz:** la lógica debe ser reutilizable y la interfaz limitarse a presentar e interactuar.
4. **Tests verificables:** cada cambio debe validarse con `node --test` cuando proceda y con Chrome DevTools.
5. **Datos protegidos:** conservar el formato y la compatibilidad de los datos del usuario; no perder sesiones.
6. **Idioma coherente:** código, comentarios y textos visibles estarán en español claro.
